# RP APP 역할·권한 매트릭스

**버전:** 0.1
**기준일:** 2026-08-01
**목적:** 학생·코치·학부모·관리자의 데이터 접근 경계와 최종 책임을 실제 인증 구현 전에 확정합니다.

## 1. 역할 정의

| 역할 | 책임 | 기본 접근 원칙 |
|---|---|---|
| 학생 | 자신의 공부·실기·컨디션·일정·상담을 기록하고 공개 범위를 결정 | 본인 데이터의 주 사용자이자 학부모 공개 범위의 결정자 |
| 코치 | 배정 학생의 훈련·실기·컨디션을 확인하고 과제·피드백·상담을 제공 | 활성 배정 관계가 있는 학생에게만 업무 목적 범위로 접근 |
| 학부모 | 코치 문의와 학생이 공개한 요약 확인 | 문의만 기본 허용, 나머지는 학생의 항목별 공개가 있을 때만 접근 |
| 관리자 | 계정·관계·동의·AI 승인·사용량·감사 이벤트 관리 | 운영에 필요한 최소 정보만 접근하고, 상담 원문 상시 열람 권한은 갖지 않음 |

## 2. 권한 기호

- `본인`: 본인 데이터만 생성·조회·수정
- `담당`: 활성 학생-코치 관계가 있는 학생만 업무 범위에서 접근
- `선택 공개`: 학생이 해당 항목을 명시적으로 공개한 경우에만 요약 조회
- `운영`: 계정·관계·상태·감사 등 운영 메타데이터 관리
- `없음`: 기본 접근 금지

## 4. 학부모 공개 정책

학부모 기본 권한은 `코치에게 문의` 한 가지입니다. 아래 네 항목은 학생이 각각 공개한 경우에만 요약을 표시합니다.

1. 출결 확인
2. 계약·결제 진행 상태
3. 학업 요약
4. 실기 기록 요약

다음 정보는 공개 설정과 관계없이 학부모 화면에 자동 표시하지 않습니다.

- 학생과 코치의 전체 대화
- 개인 멘탈 기록과 상담 원문
- 건강·통증·부상 상세 메모
- AI 질문과 답변 원문
- 성적표·영상·계약서·결제 원본

## 5. 관리자 접근 원칙

- 관리자는 모든 데이터를 보는 최고 권한이 아니라 운영 경계를 집행하는 역할입니다.
- 학생 상담과 메시지 원문은 기본 관리자 화면에 노출하지 않습니다.
- 원문 접근이 필요한 안전·보안 사건은 사유, 접근자, 시각을 감사 이벤트로 남깁니다.
- AI 승인은 사용자 단위와 기능 단위로 분리하고 일일 한도를 함께 설정합니다.
- 계약서·결제 원본은 Google Workspace를 최종 기준으로 유지하며 앱에는 진행 상태와 외부 문서 참조만 둡니다.

## 6. 기술적으로 강제해야 하는 규칙

1. 역할 이름만으로 접근을 허용하지 않고 활성 관계 테이블을 함께 확인합니다.
2. 학생-코치 메시지는 해당 대화 참여자만 조회합니다.
3. 학부모 요약 API는 공개 설정을 서버에서 다시 검증합니다.
4. AI 요청은 인증, 승인, 기능 허용, 일일 잔여량을 모두 통과해야 합니다.
5. 공개 로그와 분석 이벤트에 성적·건강·메시지·영상 원문을 넣지 않습니다.
6. 역할 전환 미리보기는 개발 전용이며 Production 인증을 대신하지 않습니다.
7. NORE API, webhook, 자동 전송 권한은 어떤 역할에도 부여하지 않습니다.
